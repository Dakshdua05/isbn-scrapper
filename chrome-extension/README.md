# Amazon India ISBN Finder extension

1. Open Chrome and go to `chrome://extensions`.
2. Turn on **Developer mode**.
3. Select **Load unpacked**.
4. Choose this `chrome-extension` folder.
5. Pin **Amazon India ISBN Finder**, open it, and enter one book title per line.

You can also use the deployed website at `https://isbn-scrapper.vercel.app`. Paste titles or upload a picture there; the installed extension searches Amazon India in background tabs and sends the results back to the website as one copyable message.

The extension searches Amazon India in background browser tabs and extracts ISBN-13 values from the matching product page. If Amazon displays a CAPTCHA, open `amazon.in` in a normal tab, complete the CAPTCHA, and then retry the lookup.
